# Dashboard de desempeño comercial — Andes Retail Group

Proyecto del bootcamp de Análisis de Datos de TripleTen (Sprint 10). Construcción de historias visuales claras mediante un dashboard ejecutivo.

## Objetivo

Comunicar el desempeño comercial 2024–2025 de Andes Retail Group (operaciones en Perú, Chile y Colombia) mediante un dashboard que permita a stakeholders pasar de una lectura ejecutiva general a un análisis más profundo de las causas detrás de los resultados.

## Qué se hizo

- **Preparación de datos**: estandarización de formatos de fecha, corrección de tipos de datos y creación de una columna condicional de nivel de venta.
- **Diseño del dashboard**: planificación explícita de dos vistas —*Overview* (KPIs generales: ingresos, ganancia, margen, unidades vendidas, evolución temporal, comparación por país/región/categoría) y *Detalle* (estacionalidad, relación precio–volumen, rentabilidad por segmento)— con justificación del tipo de gráfico elegido para cada pregunta de negocio.
- **Construcción**: desarrollo de ambas vistas en la herramienta de BI, con jerarquía visual y filtros interactivos (año, fecha, segmento de cliente).
- **Narrativa SCQA**: redacción de la historia de datos (Situación–Complicación–Pregunta–Respuesta) conectando los hallazgos del dashboard con recomendaciones de negocio concretas (oportunidades en Colombia y en temporada de invierno).
- **Comunicación ejecutiva**: mensaje breve tipo Slack resumiendo los insights principales para stakeholders.

## Herramientas

Power BI / Tableau (herramienta de BI para el dashboard interactivo).

## Resultado

Proyecto evaluado y **aprobado** por el equipo de revisión de TripleTen: *"El dashboard consigue pasar de una visión general del negocio a un análisis más específico de geografía, clientes, productos, estacionalidad y comportamiento de las ventas."*

`notebook.ipynb` — guía y narrativa del proyecto (planificación, diseño y storytelling del dashboard). El archivo del dashboard interactivo (.pbix) se entregó directamente a través de la plataforma del bootcamp.
